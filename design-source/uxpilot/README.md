# UX Pilot Design Source

Place raw UX Pilot HTML exports in this folder.

Rules:

- Preserve raw exports unchanged.
- Do not overwrite exports during implementation.
- If a design is superseded, add the newer export and update `docs/DESIGN_SOURCE.md`.
- Treat UX Pilot HTML as a visual design specification, not production code.
- Use `Build-FirstLineFromUXPilot` from the client repo after adding the export.
